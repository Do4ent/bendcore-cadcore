📦 ДЛЯ WINDOWS ПОЛЬЗОВАТЕЛЕЙ:

1️⃣  БЫСТРЫЙ СТАРТ (без компиляции):
   • Скачайте bendcore_app.exe
   • Запустите: bendcore_app.exe
   • Готово! ✓

2️⃣  КОМПИЛЯЦИЯ ИЗ ИСХОДНИКОВ:
   
   Требования:
   • Visual Studio 2022 или MinGW-w64
   • CMake 3.20+
   • C++17 компилятор
   
   Инструкции:
   • Откройте bendcore-windows-build.bat
   • Запустите: bendcore-windows-build.bat
   • Приложение скомпилируется и запустится автоматически

3️⃣  РУЧНАЯ КОМПИЛЯЦИЯ:
   
   С Visual Studio:
   ────────────────
   mkdir build-windows
   cd build-windows
   cmake -G "Visual Studio 17 2022" -A x64 ..
   cmake --build . --config Release -j 4
   cd Release
   bendcore_app.exe
   
   С MinGW:
   ──────────
   mkdir build-windows
   cd build-windows
   cmake -G "MinGW Makefiles" ..
   cmake --build . --config Release -j 4
   bendcore_app.exe
